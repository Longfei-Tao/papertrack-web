# 部署教程（手把手版）

> 适用：第一次部署、对命令行不太熟悉的同学。后端用 Cloudflare Pages + D1，全程免费、无需绑卡。
> 目标：把本项目上线，拿到一个公网链接分享给课题组成员。

---

## 0. 准备两样东西

1. **Cloudflare 免费账号**
   打开 https://www.cloudflare.com 注册，不用绑卡。
2. **Node.js（已装可跳过）**
   打开 https://nodejs.org 下载「LTS」版，一路下一步安装。装完重开命令行。

---

## 1. 打开命令行，进入项目目录

在仓库文件夹里打开终端：

- **Windows**：在文件夹地址栏输入 `cmd` 回车；或按住 `Shift` 右键「在此处打开终端」。

然后进入项目目录（把路径换成你实际的）：

```bash
cd <你的项目目录>
```

后续所有命令都在这个目录里执行。

---

## 2. 安装并登录 Cloudflare 工具

```bash
npm install -g wrangler
wrangler login
```

`wrangler login` 会弹出浏览器，登录你的 Cloudflare 账号并点授权即可。

---

## 3. 创建数据库（只做一次）

```bash
wrangler d1 create papertrack
```

屏幕上会返回一段信息，里面有一行：

```
database_id = "xxxx-xxxx-xxxx-xxxx"
```

**复制这一长串 id**，下一步要用。

---

## 4. 把 id 填进配置文件（关键一步，别填错）

用编辑器打开 `wrangler.toml`，找到这一行：

```toml
database_id = "4d48e2b4-25eb-4a75-b37e-daf9c8db75c5"
```

把引号里的内容**整个替换**成第 3 步复制的 id，例如：

```toml
database_id = "a1b2c3d4-1234-5678-90ab-cdef12345678"
```

保存关闭。**只改这一行**，其他内容不要动。

> 小知识：`database_id` 只是数据库的「门牌号」（标识符），不是密码——光有它别人进不了你的数据库。真正要保密的是 Cloudflare 的 API Token，本项目通过 GitHub Actions 的 secrets 管理，不会写进代码。

---

## 5. 建表（把数据库结构写进去，只做一次）

```bash
wrangler d1 execute papertrack --file=./schema.sql
```

看到 `success` / `OK` 字样就说明表建好了。

---

## 6. 部署上线

```bash
wrangler pages deploy public
```

第一次会问你项目名称，直接回车用默认的 `papertrack-web` 即可。跑完末尾会给出一个网址，类似：

```
https://papertrack-web.xxxx.pages.dev
```

**这个网址就是你要分享给所有人的链接。** 记下来。

---

## 7. 上线后怎么用（你的课题组落地）

1. 浏览器打开上面那个 `*.pages.dev` 链接。
2. 点「注册 / 加入」→ 选 **创建课题组**，填课题组名 + 你自己的登录密码。你自动成为该组管理员（admin）。
3. 进系统后，打开「课题组管理」，里面有一条自动生成的**成员邀请码**，点「复制」。
4. 把下面两样发给其他成员：
   - 网站链接（`*.pages.dev`）
   - 那条邀请码
5. 他们打开链接 → 点「注册 / 加入」→ 选 **凭邀请码加入** → 填邀请码 + 自设用户名密码 → 自动进组。
6. 全员都能看到同一份进度；各自只能改自己名下的论文。

> 想让某人也当管理员？在「课题组管理」里生成一条「管理员」角色的邀请码，单独发给他即可。默认是普通成员，可之后升级。

---

## 8.（可选）先本地试跑再上线

不想直接上线、想先在电脑上试试全流程，有两种方式：

### 方式 A：零依赖预览（推荐，最简单）

项目自带内存版预览服务，不需要 wrangler、不需要数据库：

```bash
node start.cjs
```

会自动启动服务并打开浏览器访问 `http://localhost:4173`。**请用这个地址访问**，不要直接双击 `public/index.html`。Windows 用户也可以直接双击文件夹里的 `start.bat`。

> 内存版数据重启即清空，只适合本地看效果和试流程。

### 方式 B：wrangler 本地模拟（接近线上环境）

```bash
wrangler pages dev public
```

浏览器开 `http://localhost:8788` 即可模拟。注意：本地测试也需要先建一次本地表：

```bash
wrangler d1 execute papertrack --local --file=./schema.sql
```

如果本地报错搞不定，不用纠结，直接按上面第 3–6 步走线上部署就行。

---

## 常见问题

- **报错 “database_id not found / binding DB”**：说明第 4 步没填或填错，回去核对 `wrangler.toml`。
- **页面能打开但登录报错**：说明第 5 步建表没成功，重跑一次 `wrangler d1 execute ...`。
- **邀请码想作废 / 限制人数**：在「课题组管理」里可停用邀请码，或创建时设最大使用次数。
- **以后想给其他课题组用**：别人直接打开链接点「创建课题组」就能自建一组，数据互相隔离，你什么都不用做。
- **忘记密码**：目前账号在自己组里，重置需管理员在数据库操作；上线前先记好各自密码。

---

## 一句话流程回顾

装 wrangler → 登录 → `d1 create` 拿 id → 填进 wrangler.toml → `d1 execute` 建表 → `pages deploy` 上线 → 打开链接创建课题组 → 复制邀请码发给成员。
